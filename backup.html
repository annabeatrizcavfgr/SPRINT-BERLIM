Backup e restauração dos dados

Verificando seu login…

1. Baixar backup deste servidor

Gera um arquivo .json com tudo: obras, usuários e papéis, e todos os documentos (semanas, metas, restrições da Matriz GUT, projeções…). Não altera nada aqui. Só planejador.

2. Restaurar um backup neste servidor

Lê um arquivo de backup e grava os dados neste servidor (). Quem já existe com o mesmo identificador é atualizado; nada é apagado. Pode repetir sem duplicar.
